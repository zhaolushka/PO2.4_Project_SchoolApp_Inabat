# SchoolApp

SchoolApp is a simple .NET MAUI application created during the MAUI course project.

## Technologies

* C# 14
* .NET 10 MAUI
* MVVM pattern
* ObservableCollection
* XAML

## Pages

### MainPage

* Welcome screen
* Data binding with `{Binding ...}`
* Live UI updates using `INotifyPropertyChanged`

### StudentsPage

* Displays a list of students
* Uses `ObservableCollection<Student>`
* Add new student form
* Navigation to student details

### StudentDetailPage

* Shows selected student information

## Features

* Cross-platform MAUI application
* MVVM architecture
* Live data binding
* Dynamic list updates
* Shell navigation

## Project Structure

* `Models/` — application models
* `ViewModels/` — MVVM logic
* `Pages` — application UI

## Author

Student project for the .NET MAUI course.
